第 4 章 · 4.4 K 近邻算法/习题 4.5
算法题 · 中等

用 K 近邻回归预测有机污染物的水生急性毒性

以 546 种化合物的分子结构描述符为输入，用 KNN 回归预测其对大型溞的 48 小时急性毒性 pLC50。本题的重点不是调包，而是亲手把距离、标准化与 K 值选择做一遍。

快速开始

# 1. 克隆仓库，数据、代码和判分脚本都在里面
git clone https://github.com/Yduidui/knn.git

# 2. 进入本题目录
cd knn/p/4-5/starter

# 3. 安装依赖，只有 numpy 和 pytest
pip install -r requirements.txt

# 4. 自测，10 项全绿即完成
pytest -q

# 5. 打印交叉验证曲线与测试集指标
python knn_tox.py

没装 git 的话，下载 starter.zip（13.8 KB），解压后从第 3 步开始。两边的文件完全一样。

数据说明

前 8 列为分子描述符，最后一列为响应变量。文件为 UTF-8 带 BOM 的 CSV，第一行是表头。

列名含义取值范围
TPSA_Tot拓扑极性表面积 TPSA(Tot)0 – 347.3
SAacc氢键受体表面积 SAacc0 – 572.0
H_050连有 5 个氢原子的碳原子数 H-0500 – 18
MLOGPMoriguchi 辛醇-水分配系数 MLOGP−6.4 – 9.1
RDCHI支化度指数 RDCHI1.0 – 6.4
GATS1p磷原子的二维自相关 GATS1p0.3 – 2.5
nN分子中氮原子个数 nN0 – 11
C_040连有 4 个重原子的碳原子数 C-0400 – 11
LC50毒性终点 pLC50，即 LC50 的负对数，值越大毒性越强0.1 – 10.0

先看这一列：8 个描述符的跨度从 0.3 到 572，相差三个数量级。不做标准化，欧氏距离会被 SAacc 和 TPSA_Tot 完全主导，其余六个特征几乎不起作用。

任务

  1. 以训练集各特征的均值与标准差对特征做标准化，测试集沿用同一套参数。
  2. 实现 KNN 回归：以欧氏距离度量样本间的相似性，对每个待测样本取距离最近的 K 个训练样本，以它们 pLC50 的算术平均值作为预测值。
  3. 令 K 分别取 1 至 15，用 5 折交叉验证估计各 K 值对应的预测误差，绘出 K 与误差的关系曲线，并确定最优 K。
  4. 在测试集上报告最优 K 对应的 RMSE 与 R²，并说明：为什么 K=1 时误差明显偏大？K 增大到一定程度后，误差为什么不再继续下降？

评分点

数据划分与标准化2 分
距离计算与近邻选择3 分
交叉验证与 K 的选择3 分
指标计算1 分
结果讨论1 分

数据来源

数据取自 UCI 机器学习仓库公开数据集 QSAR aquatic toxicity（ID 505），许可为 CC BY 4.0，可自由使用与再分发。
